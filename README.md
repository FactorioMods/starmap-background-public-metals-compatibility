# Better StarMap Background: Metal Compatibility

Keep Better StarMap Background working when the updated Metal and Stars graphics providers are installed. This independent adapter redirects the affected Mirandus orbit icon to the active graphics provider while preserving orbit geometry, icon dimensions and the other background choices. It does not copy the background mod's artwork or code.

Requires Factorio 2.1.24 and [Better StarMap Background](https://mods.factorio.com/mod/Better_Starmap_Background). Native checks verified the evaluated icon path, dimensions and asset against the active Metal provider. The original background mod remains required and unchanged.
